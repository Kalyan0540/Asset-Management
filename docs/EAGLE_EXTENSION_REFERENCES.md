# Eagle browser extension references

The original screenshots are inline in the Atlas project conversation. Use the index below to find them by the message and screen shown.

| Reference | Screenshot | What it shows |
|---|---|---|
| ECE-01 | Eagle extension menu in the Chrome plugin request | Save URL, Batch Save, three screen capture modes, Drag Feature and Preferences. |
| ECE-02 | Eagle extension Preferences in the Chrome plugin request | Light, Dark and System appearance, plus options for how capture is presented and where downloads are handled. |
| ECE-03 | Eagle extension Batch Save in the Chrome plugin request | Image grid with selection, search, resolution, format and domain filters, plus folder and tag controls. |
| ECE-04 | Second screenshot in the 19 November drag-overlay follow-up | Starting to drag a web image or video brings up the overlay over a dimmed page, per the reported behavior. The overlay shows a large dashed drop target beside a scrollable destination list and a **Create or select folder** action. |
| ECE-05 | First screenshot in the 19 November drag-overlay follow-up | **Eagle is not open yet** appears over the page when the desktop app is closed. The prompt offers **Open Eagle**, **Cancel**, and a troubleshooting link for cases where Eagle is already running. |

For Atlas design reviews, use ECE-04 when discussing destination selection during a drag and ECE-05 when discussing recovery if the desktop app is unavailable. The screenshots do not establish which video sources can be saved, or whether opening Eagle resumes the original drag.
