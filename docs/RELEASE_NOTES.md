# Atlas 0.9.0

- Write with live Markdown headings and inline Atlas images. Use the caret-positioned slash menu and searchable item picker to link, embed or connect multiple items.
- Open separate workspace tabs and view a note beside its connections. The graph keeps positions and camera while connections change and offers tag and relationship filters plus a keyboard-accessible connections list.
- Preview folder deletion and undo it without losing originals. Searchable tag and folder filters support include and exclude choices. Resize both side panels, and find the main commands under the desktop menus.
- Inspect color coverage, copy swatches in several formats, select a primary color, and find related colors. Export originals, notes, CSV metadata, or a resized PNG, JPEG, or WebP.
- Use a local Ollama model for writing drafts and batch organization proposals. Review or selectively apply descriptions, folder memberships and item links. Generic MCP continues to support compatible desktop agents.

# Atlas 0.8.0

- **Atlas Capture** saves a URL, selected text, chosen images or a screenshot from Chrome into the active desktop library.
- Batch save lets you filter images by size, format and domain before choosing what to save. Right-click, drag-and-drop and optional double-click text controls provide shortcuts on the current page.
- Pair the extension once using **Browser Capture → Copy Pairing Key** in Atlas. The extension includes default tags and system, light and dark appearance.

## Atlas 0.7.0

- Atlas saves note and inspector edits automatically and recovers pending desktop drafts. If two editors change the same field, you can choose which version to keep.
- Parent folders show their subfolders first. Search has a file-type checklist. Grid and List use directional navigation, contextual actions, and range and drag selection.
- Images open in the center with both panels available. Use `Ctrl+/` to hide or restore the panels. Markdown peeks render text, and supported videos get thumbnails.
- The graph has a library-wide view, a local view for an item's neighbors, search, and connection highlighting.
- This release also includes the library merge, tag tools, and reverse image search developed for 0.6.0.

Choose the installer for your computer under **Assets**. [Desktop setup](https://github.com/Kalyan0540/Asset-Management/blob/v0.7.0/docs/GETTING_STARTED.md) · [Android preview](https://github.com/Kalyan0540/Asset-Management/releases/tag/android-v0.3.0-preview)

## Atlas 0.6.0 development milestone

- Choose **Library → Merge Libraries…** to combine two Atlas libraries into a separate copy. The merged library keeps nested folders, original files, item history, note links and relations. Open either source library again from its existing location.
- In **All Tags**, click the pencil next to a tag to review a rename or merge. Tag groups can also be renamed, combined or removed.
- Choose **Search web by image** from an image's item menu. Atlas prepares a temporary copy for Google Lens or TinEye. You decide whether to upload it in your browser.

The 0.6.0 development changes shipped with the 0.7.0 installers. ## Atlas 0.5.1

This build preserves the first character typed immediately after inserting a Markdown slash command.

- Compact desktop gallery with captions beneath thumbnails, smaller navigation and inspector controls, and System, Light and Dark appearance.
- Hide either side panel, peek at images and video from the magnifier, zoom the main image preview, or play video in its tile while hovering.
- Browse a real folder tree, create subfolders, and include their items in the parent view. New Eagle imports preserve the tree. The sidebar offers a preview and repair for older flattened imports.
- Save a group of filters as a Smart Folder. Optional rules add tags or folder membership on future desktop imports. Use All Tags to find tags and organize tag groups.
- Paste images into the library, search recent terms, use a searchable item menu, and undo moving an item to Trash.
- Open recent libraries from the sidebar. Export selected originals and notes to a chosen folder. The catalog export and full library backup remain distinct.
- The local read-only MCP server remains available to compatible agents through **Agents → Copy Read-only MCP Configuration**, with a Codex shortcut in the same menu. Markdown, links, relations, history and graph remain available.

[Setup guide](https://github.com/Kalyan0540/Asset-Management/blob/v0.5.1/docs/GETTING_STARTED.md) · [Android preview](https://github.com/Kalyan0540/Asset-Management/releases/tag/android-v0.3.0-preview)

Android continues to use its existing offline preview interface. These desktop updates leave additional integrations such as cross-library merge, reverse-image providers, hosted ChatGPT access, and automatic device sync for later.

# Atlas 0.4.1

Choose a related item in the inspector and click **Save changes**. Atlas now saves the selected relation directly, and you can click the saved link to open its target. Saving a Markdown note keeps the current Write or Read view.

The same library opens after updating. This desktop update keeps the current Eagle import behavior. The Android preview is unchanged.

Download the DMG for your Mac chip or the 64-bit Windows installer under Assets. [Setup guide](https://github.com/Kalyan0540/Asset-Management/blob/v0.4.1/docs/GETTING_STARTED.md)

# Atlas 0.4.0

- Hover over an image or video to reveal its magnifying glass. Click to open Quick Preview. Switch between Grid, Justified and Waterfall using the gallery toolbar.
- Select an image to see its dimensions and copy dominant colors from the inspector. Imported Eagle items also show the original rating and source link when available.
- Create folders with an inline name and notes with an automatic title. The full-width Markdown workspace includes slash commands, a formatted reading view, links to notes and assets, and image embeds. Saved links appear in the graph when both items are in view.
- Connect local Codex through **Agents → Copy Codex MCP Setup**. Codex can search the library, read notes and access supported images without setting up Ollama.

Download the DMG for your Mac chip or the 64-bit Windows installer under Assets. The macOS download uses ad-hoc signing and the Windows installer has no verified publisher signature.
