# Atlas design references

The 20 screenshots below are indexed in the order they appear in the 18 November feedback message. The original screenshots were shared inline in the Atlas conversation. The folder also holds 16 frames from the earlier Eagle screen recording. Use the screenshots and frames as references for workflow, control placement and hierarchy.

## Screenshots in the feedback message

| # | Screenshot | Detail to carry into the Atlas plan |
|---|---|---|
| 01 | Eagle parent folder | Subfolder tiles appear above the Contents grid. The **Show subfolder contents** toggle is visible above the assets. Folder context fills the inspector, and the tree preserves hierarchy. |
| 02 | Folder context menu | New folder and subfolder, move, Quick Access, rename, copy link, auto-tag, password, sort, expand or collapse levels, duplicate, export, add to another library, descendant toggle, folder icon and color, and remove folder. Group the common actions first. Record the rest as choices for future scope. |
| 03 | Folder tree and Create Folder tooltip | Fine guide lines show nesting. A small add control near the section heading has a tooltip and keyboard hint. Folder actions do not need to sit on every row. |
| 04 | In-place asset detail | Image fills the center with navigation and inspector intact. Top controls include Back, zoom level and Fit to Window. Use the reference for the transition and proportions. Atlas plan calls for keyboard navigation between items and compact zoom controls. |
| 05 | Selected-item inspector | Media preview, palette, title, notes, source URL, removable tags and folders, rating, dimensions, size, format, dates and a single Export entry point. Observe the pin control as a possible panel customization. |
| 06 | Export options | Package, export to computer, format and dimension export, and CSV. Capture the grouping and keyboard hints. Discuss Atlas packages and Eagle-format export compatibility separately. |
| 07 | Color swatch hover | Outline the focused swatch and show the hex value and coverage percentage when available. |
| 08 | Color swatch context menu | Find similar items, copy the color as HEX, RGB, RGBA, HSL, HSV, HWB or CMYK, and set the primary color. Use consistent normalized values across swatches and filters. |
| 09 | Types filter | Searchable file extensions with checkboxes and result counts, and include or exclude interactions. Integrate the entry point into the main search field. |
| 10 | Folder filter | Searchable folder choices with checkboxes, counts, Uncategorized and match controls. |
| 11 | Tags filter | Search terms, tag groups, selected filters, tag and Untagged counts, include or exclude behavior, match controls and Escape. |
| 12 | Color filter | Gradient picker, hue strip, preset swatches and a hex field. Ensure keyboard input and pasted inspector values work. |
| 13 | Native menu headings | File, Edit, Find, Organize, View, Window, and Help alongside Library. Atlas may need its own Agent commands. |
| 14 | File menu | Group New, folders and smart folders, imports, and exports. The reference includes folders, links, packages, integrations, automatic import and CSV. |
| 15 | Edit menu | Group rename, undo/redo, cut/copy/paste, copy variants, duplicate, thumbnail generation and overrides, selection, folder or image edits, removal from a folder and Trash. Native writing tools can be grouped with writing or AI commands. |
| 16 | Find menu | Search the current view or library, filter the sidebar, advanced filters, search by image, jump to or add to folders, and duplicate search. |
| 17 | Organize menu | Add or clear tags, assign folders or reuse the last folder, set or clear a rating, and copy or paste tags. |
| 18 | View menu | Library views, Grid/List and alternate layouts, scrolling, zoom, fit, grayscale, file open/reveal actions, side panels, name and info visibility, subfolder contents, and presentation. Keep Grid and List primary in Home and expose applicable options as menu commands. |
| 19 | Help menu | Searchable Help, shortcuts, tutorial, extensions, feedback, release notes, error logs and export diagnostics. Match the organization to the features Atlas ships. |
| 20 | Obsidian graph and tabs | Graph in its own tab with the tree still visible. Named nodes connect on a quiet canvas. Search and toggles for tags, attachments, existing files and orphans sit alongside groups, display and layout controls. Also use this as a reference for independent tabs and optional split panes. |
